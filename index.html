Privacy Policy

Last updated: October 7, 2026

Simple Flash Cards is an offline flashcard application developed by Vishap Interactive. This Privacy Policy explains how the application handles user data.

Data Collection

Simple Flash Cards does not collect, transmit, sell, or share personal data with Vishap Interactive or third parties.

The application does not use analytics, advertising SDKs, tracking technologies, crash reporting services, or user accounts.

Data Stored on Your Device

The application may store the following information locally on your device:

  • flashcard decks and deck names;
  • flashcard text and comments;
  • deck tags and language settings;
  • learning progress and card status;
  • images added to flashcards;
  • application preferences such as theme, interface language, haptic feedback, and animation settings.

This information remains on your device and is not transmitted to Vishap Interactive.

Images and Files

When you choose an image, JSON file, or ZIP archive, Simple Flash Cards accesses only the file explicitly selected by you through the Android system file picker.

Images added to flashcards are copied into the application's private local storage. The application does not request unrestricted access to your photo library.

Import and Export

Simple Flash Cards allows you to import and export flashcard decks and library backups. Import and export operations occur only when initiated by you.

Exported files are saved to a location selected by you. If you choose a cloud storage provider such as Google Drive or another provider through the Android system file picker, the exported file may be transferred to that provider at your request.

Vishap Interactive does not receive or control exported files.

Backups

Android system backup of application data is disabled. Backups can be created manually using the application's export functionality.

Data Deletion

You can delete individual flashcards and decks from within the application. Deleting a deck also deletes its associated locally stored card images.

Uninstalling Simple Flash Cards removes the application's locally stored data from the device, subject to the behavior of the Android operating system.

Children's Privacy

Simple Flash Cards does not knowingly collect personal information from children or adults because the application does not collect personal data.

Changes to This Privacy Policy

This Privacy Policy may be updated if the application's functionality or data practices change. The latest version will be available on this page.
